# Flutter Projects

Flutter 跨平台应用集合。

## 项目列表

### miniarm_flutter

蓝牙机械臂遥控控制应用，通过 BLE 连接控制 5 轴机械臂。

- **技术栈**: Flutter + flutter_blue_plus
- **功能**: BLE 设备扫描连接、关节角度滑块控制、方向键移动控制、预设姿态一键切换
- **平台**: Android / iOS

### smart_watering (匠心农场)

智能浇水控制应用，通过巴法云 HTTP API 远程监控土壤湿度并控制浇水系统。

- **技术栈**: Flutter + Provider + HTTP
- **功能**: 土壤湿度实时监控、水泵远程控制、自动/手动模式切换、双阈值滞回控制
- **平台**: Android / iOS / Web / Windows / macOS / Linux
